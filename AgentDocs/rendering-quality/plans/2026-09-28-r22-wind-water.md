## Source facts and scope

R8 SceneGISWaterSurface triangulates a flat CoplanarPolygonGeometry. Four analytic normal
frequencies animate shading only; WaterFrame already schedules all owned water commands
after opaque geometry and preserves common depth, transmission, reflection and picking.

Add optional caller-owned SceneGISWindWaves to that surface. Two complementary spectral
bands use deterministic wind/fetch/depth-dependent JONSWAP/TMA spectra, finite-depth
dispersion, GPU inverse FFT, horizontal displacement and geometric normals. Parameters
are wind speed (m/s), local travel direction, effective fetch (m), mean water depth (m),
amplitude multiplier and choppiness. This is visual wind-wave synthesis, not hydraulic
flow, measured bathymetry, flooding, breaking-wave CFD or a weather prediction.

Water geometry is tiled and clipped to the same original polygon including holes.
Distance-selected mesh density and identical finest-resolution tile edges keep geometry bounded and
watertight. Conservative displaced bounds preserve culling; normal filtering controls
distant shimmer. Legacy surfaces without windWaves retain their flat geometry/API.
The caller owns a reusable waves object; surfaces borrow it within one rendering context.
Simulation follows Scene time, updates once per changed time/configuration and does no
CPU readback. Hidden surfaces do not schedule simulation.

2. Integrate tiled displaced meshes into owned WaterSurface/GLSL; retain R8 upstream
   seams. Test polygon holes, displaced depth/picking, culling bounds and shared tile

3. Add a dedicated Xuanwu Lake example with local deterministic shoreline data and
   source/license attribution, explicit illustrative bottom/landscape, overview and
   near-water cameras, wind/fetch/depth/quality controls, live mesh counts and pause. Preserve
   original PBR tab. Add links from example catalogs and a small example smoke test.
4. Run focused Specs, release/types/lint, browser visual checks and bounded GPU timings.
   Record actual resource and geometry budgets. Complete review and one local checkpoint.

## Risks and exit gate

FFT tiles are periodic; the two bands reduce obvious repetition but are not a global
fluid solver. Uniform mean depth does not refract waves around islands. Shore contact
foam remains the existing screen-depth approximation; submerged/transparent and TAA
object-motion limitations remain. Qualify correct shape, real moving geometry, stable
near/far transitions, useful wind controls and acceptable measured cost before handoff.

## Implementation notes

- Matching finest boundary vertices replace neighbor-dependent edge interpolation, avoiding a second stitching state machine. Interior cells use two triangles; only stitched edges need center fans.
- The example uses the original OSM relation 2138994 outer ring and seven inner rings, with local source/license metadata. Bottom depth and vegetation are explicitly illustrative.
- A water-only reflection guard rejects opaque lake-bed hits below the mean water plane. Existing normal-only water and general SSR behavior remain unchanged.
- GPU DFT validation exposed the native default texture Y flip; spectrum uploads explicitly use bottom-origin rows.
- Both-world physical-light and cleanup tests exposed missing wind VS defines and test cleanup after Context destruction; both are corrected.
- Validation and performance details: [R22 review](../reviews/2026-09-28-r22-wind-water.md). No upstream-owned file changed; SGP-0017 reused unchanged.
