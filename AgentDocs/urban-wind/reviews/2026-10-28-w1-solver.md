## Findings and disposition

- Fixed: explicit private source imports in Specs created a second ContextLimits identity relative
  to the built engine runtime. Solver Specs now import the barrel's private symbol, like existing
  fluid Specs. Four strict real-WebGL tests pass without stubs or skipped capabilities.
- Fixed: public Texture JSDoc referenced a non-public declaration; use a documented borrowed
  GpuTexture handle. Public properties now have separately parsed type/readonly tags; buildTs/tsc pass.
- Fixed: fixed MRT expressions belong in the approved GLSL source root, not runtime string building.
  CPU basis remains the independent numerical reference; strict collision test matches GLSL.
- Resolved tooling: HTML inline-script lint conflicts with the repository seatbelt processor.
  Example module is an external JS file with explicit browser globals; no lint configuration changes.
