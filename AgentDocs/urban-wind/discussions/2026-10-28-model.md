# Model and GPU sharing

- Type: discussion; status: resolved for W1; author: architecture; date: 2026-10-28.
- Plan: [roadmap](../plans/2026-10-28-urban-wind.md); ADR: 0193; review: pending.

Use published D3Q19 orthogonal MRT and second-order equilibrium. LES derives from deviatoric
nonequilibrium stress, without random forcing. Cs=0.12 is a starting coefficient, not universal
calibration. Fixed Cs and coarse stairs do not resolve viscous wall units or establish wall-modelled LES.
Native VoxelProvider needs CPU tile metadata; programmable particles can sample GPU uniforms but
own a separate time integrator. The wind producer must own stepping. A live public GPU descriptor
provides the narrow sharing boundary; mount producer before consumers. W3 chooses rendering from
the qualified field interface. Animated particles are neither concentration transport nor necessarily
instantaneous streamlines; those quantities must be implemented separately.
