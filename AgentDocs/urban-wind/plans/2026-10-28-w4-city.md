## Implementation scope from current source

Public simulation, explicit prism mask, live sampling, asynchronous cell queries and visualization
are available. Build/type gates pass. No SDK code or copied distributions are needed.
Create a deterministic idealized city with identical explicit prisms driving rendering and mask.
Globe/Planar differ only by rigid placement. Default assessment is 128×128×32, dx=2 m, dt=0.02 s,
physical air viscosity, specified 3 m/s wind (low-Mach headroom for local acceleration).
Preset physical-time snapshots, source controls, volume/slice/streamlines and reset/destruction
are example assembly only. No solver or generic visual logic is implemented in the example.

The Renderer has no timer-query wrapper. Add an owned optional instrumentation helper using
EXT_disjoint_timer_query_webgl2 around the producer's full step batch (velocity plus tracer).
It never executes simulation, changes parameters or blocks for results. Expose completed
milliseconds/step, batch steps and version, and explicit unsupported state. Disjoint samples
are discarded; existing external timer queries are not nested. Resource ownership is bounded.

## Acceptance

Measure actual browser GPU, atlas bytes, step budget and physical/wall elapsed ratio. Run a finite
city warmup, inspect sparse velocity/density/CFL samples and actual screenshots in both worlds.
Check outlet proximity and numerical limits explicitly; adjust grid/case only from observed facts.
Report idealized geometry, wall/LES/outlet/transport limits and independent engineering validation
requirement. Complete SDK integration documentation with minimal calls, immutable vs live controls,
consumer order and asynchronous query/ownership semantics. Scoped checks, full release/types,
review and final phase commit. Project owner's visual acceptance remains external.
