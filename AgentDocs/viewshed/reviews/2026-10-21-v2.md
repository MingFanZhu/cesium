## Remaining boundaries

Finite observer resolution and source LOD limit subpixel occluders. Camera-scaled
models, frozen traversal, stereo, transparent media and exact geometry queries
are outside the first API profile. V3 records actual sample performance and
remaining visual findings; it does not infer GPU time from CPU submission time.
