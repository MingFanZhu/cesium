## Frozen API and semantics

SceneGISVideoProjection extends PostProcessStage and composes ObserverState.
Borrow HTMLVideoElement, expose video replacement, opacity [0,1], flipY (false),
showFrustum, setView, analysisReady, videoReady, projectionReady, status, error /
errorEvent and statistics. Geometry / sources parameters match Viewshed. Contain
the video inside the angular rectangle, leaving letterbox regions unchanged;
do not stretch or automatically change FOV. Native Texture flipY handles HTML
top-left input; public flipY is an additional presentation flip.

Require requestVideoFrameCallback / cancelVideoFrameCallback. Owned media helper
marks new frames dirty, requests rendering and uploads only in stage.update.
Events invalidate on seeking / source reset / resize and load or seek completion.
Keep GPU texture warm while disabled; cancel notification while disabled. Destroy
removes events/callbacks and texture without touching playback or stream tracks.
Failures are reported and remain until explicit replacement or source reload.

Native PostProcessStageCollection executes user stages after tone mapping, which
includes LDR gamma-only display conversion (ADR-0161). Composite SDR RGB directly,
preserve destination alpha. Opaque depth defines receivers; translucent surfaces
are not receivers/occluders. Because this display overlay follows translucent
composition, it can also overlay transparent foreground at an opaque receiver's
pixel. This limitation is explicit and tested, not claimed as optical transmission.
Correct physical transparent-foreground recomposition requires a separate future
contract; this phase adds no speculative per-object transparency capture.

## Tests and exit gate

Use a deterministic locally generated video fixture in Specs. Check real decoded
frames, pause / seek / new source / intrinsic resize, callbacks / lifecycle / errors,
upload counts, aspect / orientation, black / opacity / HDR-LDR color, offscreen
occlusion and multi-instance isolation in both Worlds. Build, build-ts, tsc and
focused lint must pass. Review and separate commit before P3 example qualification.
