## Source facts and implementation

Its coordinator is also consumed by Planar Surface and S3M through FrameState.
Extract `_SceneGISObserverState`, rename coordinator to `_SceneGISObserverPasses`,
and use `_observer` / `_sceneGISObservers` consistently. Public Viewshed remains
an independent PostProcessStage. Keep depth, terrain and guide implementations.
Extract reprojection and depth comparison to generated shared GLSL, composed with
the existing Viewshed display main. No algorithm, target size or traversal change.

Only upstream edit: Scene.js dispatch import / names inside existing SGP-0065.
Update private references in Specs and E2E. No generated file edits.
