## 委托入口与排除纪律

- Entity / DataSource / Planar wrapper 委托 Primitive、GroundPrimitive 或对应 Collection；P4b 动态实体、P4d 标注 / 透明地表、P4e 地图与 P4g 集合覆盖其实际命令入口。
- Cesium3DTileset 的 Model pnts 与 TimeDynamicPointCloud 的独立 PointCloud 分别核对；原生 EDL 注册覆盖二者，未借用其他物体深度作为点邻域。
- Model 分类线框与原生 Vector3DTilePrimitive 线框有不同路由：前者是 depth-writing 材质，后者是光照后的无光照专用覆盖；均有实际 GPU 证据。
- Moon / SkyBox 委托原生天体 / CubeMapPanorama，但 Scene 的 nativeEnvironment 与 PlanarWorld 提前门禁阻止旧环境恢复；显式加入 primitives 的 CubeMapPanorama 仍支持独立 ENVIRONMENT 背景。
- 原生 InvertClassification 被 DeferredInverse 替代；SunPostProcess 被高级环境 / 泛光替代。保留源码，不通过移除 API 规避审计。
- SceneGISReflectionProbeCollection 委托局部探针 capture，按负责人明确要求暂缓；物理天空反射与 SSR 未被该例外排除。透明对象的水面 SSR 倒影也已由负责人明确暂缓。
- WebGL2 / SCENE3D、单采样及 WebGL1 / 2D / Columbus / WebVR 排除继续遵循负责人 A 决定。没有新增模式、设备门槛、资源预算或任意外部 DrawCommand 协议承诺。
