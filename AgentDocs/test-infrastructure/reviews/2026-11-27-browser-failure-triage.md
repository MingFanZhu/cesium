## 发现和处置

| 用例               | 根因                                                                 | 处置                                                                                |
| ------------------ | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Planar 自动曝光    | 默认高级大气进入 HDR 测光输入，夹具的日光重测可能在切入夜间后才消费  | 隔离夹具输入，切换前完成日光重测，保留 20 倍缩放对应的目标曝光档位和锁定断言        |
| Globe 自动曝光     | 与 Planar 相同，关闭原生天空后仍可能加载高级大气                     | 使用同一夹具修复，独立验证 Globe 的曝光、导航与销毁                                 |
| 延迟要素样式       | 夹具给已移除的 `deferred` 控件绑定回调，初始化在加载 tileset 前退出  | 删除过时绑定，验证要素拾取、样式切换及样式纹理释放                                  |
| Planar 影像协议    | 默认大气在多协议取样期间异步就绪，改变帧缓冲颜色                     | 固定夹具渲染输入，保持六种协议的四点读回、尺寸和请求断言                            |
| Planar Viewer 集成 | 用例要求旧天空和天体命令执行，并用线性像素预期直接比较显示编码结果   | 移除旧命令探针，按场景 Gamma 还原线性值后验证原色差范围，保留控制器、拾取和资源检查 |
| Planar API 集成    | 高级大气异步就绪，地表选择另一 Shader 变体，只有 Shader 身份断言失败 | 固定地表 Shader 输入，分别检查瓦片、命令、Shader 和顶点数组身份                     |

六项发现均为 `fixed`，严重度中，执行负责。初始条件下六项均复现。
开发包在 Chrome Headless 下六项通过。发行包的两项平面集成和一项影像协议也通过。
验证覆盖本次复查的用例。无新增上游补丁。
