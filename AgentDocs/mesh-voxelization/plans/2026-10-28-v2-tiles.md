## Entry and current source facts

V1 committed as `4f17f2cc05`. Native tileset prePassesUpdate processes the shared request queue; requestContent owns error reporting, expiry and scheduling. `touchTile` pins used tiles through the native cache. Calling native view traversal would overwrite display selection and add camera dependence; instead a bounded owned hierarchy walk requests required content through a narrow native hook without changing display selection arrays.

`ModelReader` handles decoded/quantized/interleaved attributes, indices, node/axis and instance transforms. Model content keeps its Model private; add an explicit triangle visitor hook rather than publish private runtime graphs. TRIANGLE_STRIP/FAN conversion in this baseline lacks a typed-array constructor `new`; V2 limits qualification to TRIANGLES and reports other modes, avoiding an unrelated native fix. Raw static meshes do not include skins, morph targets, animation or custom shader deformation.

## Detailed design

- `SceneGIS3DTilesVoxelizer({scene, tileset, grid, maximumGeometricError, ...budgets})` is an explicit one-shot primitive with `resultPromise`, status/progress, cancel/destroy. Source tileset must remain mounted directly in the same Scene. The job borrows the tileset and owns its Core voxelizer.
- Region is exactly the grid's rigid world box; conservative bounding-volume plane tests drive hierarchy traversal. Update native tile transforms, retain ADD parents, replace REPLACE parents, traverse empty/external/implicit containers. Requested source error is independent of grid width; insufficient terminal precision fails.
- Request and decode use native loader/cache/processing. Pin intersecting required tiles while gathering; no camera change, no implicit display LOD fallback, no private scene scan. Request-render mode is kept alive only while the job needs frames.
- Snapshot only after selected content is ready; native content update refreshes model/node transforms with a temporary command list restored in finally. Content-specific hook delegates to owned ModelReader adapter. Geometry is read once per selected content, with a configurable tile count per frame and byte/triangle budgets; GPU buffer reads may synchronously stall for a large individual tile.
- Results carry source completeness, selected tile URLs/errors and loading/snapshot/total timings. Failed/unloaded/unsupported content rejects the job, not an empty mask. Static source geometry includes hidden/transparent surfaces and ignores rendering clipping/style; no inference of material solidity.
- Reject source root transform changes, animation/skin/morph/customShader, non-TRIANGLES/point clouds and vertical exaggeration. Result does not guarantee a watertight manifold.
- Cancellation stops owned work and unpins on following frames; borrowed requests/cache follow native lifetime and are not forcibly cancelled if rendering still needs them. Worker and timeout released on settle/destroy.

## Affected paths

Owned Scene public adapter/private selection and ModelReader wrapper, Scene Specs, Test HTML/fixture, public integration guide, ADR/SGP/AgentDocs. Native files limited to `Cesium3DTileset.js` (request hook) and `Model/Model3DTileContent.js` (static geometry visitor). No SDK or generated-file edits.

## Validation and gate

Real native loader fixtures cover offscreen active loading, transform/instance geometry, ADD/REPLACE choice, empty/external hierarchy, missing/unsupported input, tile/cache ownership and cancel/destroy. Deterministic example in Globe and Planar provides grid/resolution control and source-vs-voxel display plus timings. Verify public exports/types and release worker. Scoped regressions for the two native seams; patch audit and final review precede V2 checkpoint.

## Risks and results

Native cache budgets may prevent an entire ROI becoming resident: timeout rejects instead of degrading precision. CPU snapshot budget does not bound one GPU read's wall time. Source geometricError is not a measured CFD surface error.

Implementation complete. Eleven Core and thirteen adapter Specs pass with WebGL validation. Full build/release, generated types and TypeScript checks pass. Actual native i3dm, composite/multiple, implicit and Draco fixtures are covered, alongside offscreen request-render loading, LOD choice, cancellation, budgets and source ownership. SDK guide and Globe/Planar example are delivered; performance and remaining scope limits are recorded in the V2 review.

One justified Core adjustment preserves exact cell-face contacts under ENU/ECEF floating-point cancellation. The added regression compares complete occupancy arrays; the example's 2 m grids now have identical surface/interior counts in both worlds. This is roundoff compensation, not geometric inflation. The source can be released after snapshots are handed to the owned Worker; request-render jobs explicitly request their initial frame. No SDK or generated-file changes.
