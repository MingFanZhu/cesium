## Measured example

Windows, local in-app Chromium 156, 1575 × 892 viewport. Four local glTF tiles, eight closed box buildings, 96 triangles; `enclosed` mode. These are one-run observations of a small analytic fixture, not a large photogrammetry throughput claim. Computation is in a CPU Worker; snapshot time includes any native GPU buffer readback. Source/point display creation is outside the job's computation timers.

| World / grid                                       | Occupancy bytes | Surface / interior cells | Load / snapshot / Worker / total ms |
| -------------------------------------------------- | --------------- | ------------------------ | ----------------------------------- |
| Planar, 128 × 128 × 32, 2 m                        | 0.50 MiB        | 24492 / 24642            | 76.4 / 2.2 / 17.5 / 167.1           |
| Globe, 128 × 128 × 32, 2 m                         | 0.50 MiB        | 24492 / 24642            | 91.7 / 4.3 / 24.9 / 190.7           |
| Planar, 256 × 256 × 64, 1 m, already loaded source | 4.00 MiB        | 105488 / 234480          | 0.0 / 17.3 / 69.2 / 182.1           |

Grid refinement changes conservative shell thickness and retained interiors as expected. Occupancy bytes exclude native model cache, mesh snapshots and enclosed-mode queue (4 additional bytes per cell). The 1 m case exceeds the separate wind solver's default cell ceiling; consumers must enforce their own budgets.
