# Discussions

discussion 保存提炼后的工程问题和方案权衡，不保存原始聊天转录。实际文档使用 `YYYY-MM-DD-<topic>.md`。

每份 discussion 使用以下结构：

```md
# Discussion: <Question>

## Metadata

- Status: `open | resolved | superseded`
- Owner role: `architecture | execution | review`
- Created: `YYYY-MM-DD`
- Updated: `YYYY-MM-DD`
- Related plan: None
- Resulting ADR: None
- Related SGP: None

## Question

## Current Cesium source facts

## Constraints

## Options

## Recommendation

## Outcome

## Follow-up actions
```

结论形成长期架构决定时提升为 ADR；形成强制规则时同步更新 Architecture 或相应 `AGENTS.md`，并在此处链接正式文档。
