## Scope and summary

检查 legacy i3dm GPU 变换顺序、CPU 初始/更新绘制球、模型总范围、共享对象和资源生命周期。
范围聚合在 SceneGIS-owned helper 内；上游仅修改 `I3dmLoader.js`、`ModelDrawCommands.js`、
`ModelDrawCommand.js`、`ModelSceneGraph.js`，43 行新增，均有成对 SGP 标记。
`ModelUtility`、`View`、Shader、普通 glTF/EXT instancing、SDK 均未修改。

## Validation reviewed

- `SceneGIS/Scene/SceneGISLegacyInstanceBounds`：4/4 通过。ChromeHeadless 156，
  `--webglValidation --failTaskOnError`，实际 WebGL，不使用 stub。
  内存生成的 GLB / i3dm 覆盖平面场景实际像素与深度拾取、3 个小角度视角、
  RTC、多个 mesh nodes 摘要共享、实例矩阵属性、父子节点和 tile 变换、销毁。
  球面 ENU、轴修正、奇异/负节点缩放和实例旋转/非均匀缩放另有全角点包含性测试。
- 原生定向回归：I3dmLoader 19/19、ModelDrawCommand 44/44、
  ModelMatrixUpdateStage 5/5、ModelSceneGraph 17/18，共 85 个通过。
  1 个 Fog stage 断言失败；InstancingPipelineStage 的 beforeAll 因 2D deferred 限制失败，
  10 个用例未能正常执行。以上两类均以修改前源码独立复现。
- 开发构建生成 ESM / IIFE / CJS 通过；`npm run tsc` 通过。
  生成文件未提交，未增加公共 API。
- 定向 ESLint、Prettier、Markdown 检查及 upstream audit 通过。
  审计确认本交付仅 4 个 upstream-owned files，无生成文件改动。
  全部 AgentDocs 的 Markdown 检查通过；全量 Prettier 检查报告 676 个既有文件警告，
  本次新增目录均通过定向格式检查，未批量格式化其他协作记录。
- `gulp prepare` 被当前依赖安装缺失 `draco3d/draco_decoder.wasm` 阻断；
  沿用已准备资源完成构建和真实 WebGL 回归，未借机修改依赖。
- 开销微基准：Node v24.9.0 / Intel i5-12490F；100,000 个平移实例初始化摘要
  14.67 ms，10,000 次暖机 primitive 更新 12.81 ms（约 1.28 μs/次）。
  此数值仅说明 CPU helper 开销，不代表整帧或 GPU 耗时。
  摘要固定 192 bytes、各 mesh nodes 共享，无新增 GPU 分配或 pass；原 CPU TRS 按原路径释放。

## Accepted risks and conclusion

系数区间包围体可能比逐实例精确并集大，增加保守可见性成本，但不缩小合法范围。
外层任意 shear 的原生 sphere transform 限制、模型动画总范围更新限制和非 SCENE3D
产品模式不由本补丁扩宽。没有本次修复遗留的 open finding，standalone gate approved。
