## Scope

Static mesh 3D Tiles deformation through an explicit CustomShader subclass,
local polygon texture, tile/command bounds integration, public declarations,
and globe/planar development examples. Approval here covers engineering readiness
for manual inspection; it does not represent owner visual acceptance.

## Summary

The owned implementation uses the native shader, material, tile scheduling and
picking paths. SGP-0064 is limited to two upstream JS files, calling owned bounds
helpers. Original bounds are preserved; disabled and unrelated shaders retain
their original behavior. There are no builtin shader changes, workers, added draw
passes, or SDK integration.

## Validation reviewed

- Owned `SceneGIS/Scene/SceneGISModelFlatten`: 7 passed.
- Native `Scene/Model/ModelDrawCommand`: 44 passed.
- Exact native `Scene/Cesium3DTile`: 29 passed.
- GPU E2E: 4/4 development and 4/4 minified release, no skipped or flaky cases.
  Globe and planar deterministic grids verify concavity, direct holes,
  unchanged exterior, depth picking, nested transforms, height changes,
  genuine tile/draw culling, disable restoration, fine/coarse LOD,
  stable texture allocation and resource destruction. Two of the four cases use
  real local photogrammetry and provide screenshots for visual assessment.
- `npm run build`, `npm run build-release`, `npm run build-ts`, `gulp tsc`,
  scoped ESLint, changed-file formatting, patch audit and diff checks passed.
  Generated declarations expose the public class and hide private bounds hooks.
- Broader substring filter: 554 passed, 10 failed. Five fail the existing
  SCENE3D-only deferred contract during non-3D transitions; five colorBlendMode
  expectations also fail against the unchanged integration-file baseline.
  They are not counted as passing qualification.
- AgentDocs markdownlint passes globally. Global Prettier reports 507 inherited
  failures outside this extension; its new/changed documents pass.
- Fixed texture allocation: 8,192 bytes. Release warm bounds-cache lookup,
  200 batches of 100 queries: p95 approximately 0.1 ms in both worlds, median
  below timer resolution. This is a bounded CPU measurement, not zero cost or a
  GPU/FPS benchmark. The per-vertex polygon loop remains proportional to edges
  after AABB rejection, capped at 256.

## Accepted risks

The globe frame defines an ENU horizontal plane, not a constant ellipsoid height.
Triangles are not split; CPU source-mesh queries/export remain unchanged.
Original photogrammetry textures retain baked shadows. Classification, animated
meshes, native 2D and composing unrelated CustomShaders are outside the profile.
Conservative bounds may refine additional tiles. A shader belongs to one Context
and must be detached before its caller destroys it.

## Conclusion

Engineering checks support presenting this prototype for owner visual acceptance.
No SDK handoff or integration is authorized before that acceptance. Public usage,
ownership and limitations are documented in
[ModelFlatten](../../../Documentation/SceneGIS/ModelFlatten.md).
