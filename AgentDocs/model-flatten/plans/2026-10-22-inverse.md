## Contract and source facts

Add constructor and mutable property `inverse`, default false. Keep the existing
vertex deformation and target local `height`; no fragment depth trick or extra
render pass. Inverse preserves the selected polygon and deforms its complement
within the consuming tileset. Direct holes belong to the complement. Invert the
existing boundary policy exactly: outer boundary stays, hole boundary flattens.
Cross-boundary triangles still slope because topology does not change.

The existing VS already evaluates concave rings and holes from a fixed edge
texture. A boolean uniform complements that result without rebuilding GPU data.
The owned bounds helper currently excludes spheres outside the polygon AABB;
that exclusion must only apply in normal mode. In inverse mode use conservative
source/projection unions for all spheres, including fully protected spheres,
without an unsafe containment shortcut. Invalidate bounds caches on mode changes.
Keep native scheduling, picking, model transforms and caller ownership intact.
