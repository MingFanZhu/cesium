## 源码事实与方案

Style 编译对象可被多个 Layer 借用，不能在 Style 内写入某个 Layer 的可变状态。
Layer 已按 entry/style signature 保留无关批次，Worker 接收 raw tile 并仅准备变化的 records；
symbols 将不变 layout 和逐帧 paint 求值分开。利用这些边界实现：

1. Layer 持有 feature/global state；增加 set/get/removeFeatureState、setGlobalStateProperty/getGlobalState。
   明确 vector source/sourceLayer/id 身份，JSON 值、复制隔离、合并和删除语义。
2. feature-state/global-state 限 paint；filter/layout/root state defaults 本轮拒绝，不暗中扩展布局协议。
   Style.evaluateLayer 增加可选计算 context，Style 本身继续无可变运行时状态。
3. Worker 返回每 source-layer 的原始 feature ID 索引，状态只失效含该 ID 且依赖变化 key 的 entry/style。
   未解析 entry 使用当时最新快照；旧任务在 normal update 丢弃，旧画面保留到新结果按预算发布。
4. 复用 Worker 重建受影响的几何批次；不请求瓦片，不重建无关层/瓦片。
   此阶段不承诺每 feature 的 GPU subrange paint 更新；对持续高频海量状态属于后续性能范围。
   标注 paint 直接重新求值、更新已有 buffer，不重新请求字库或 shaping。
5. Test 两世界增加点击选中和全局强调；Specs 验证身份、依赖、局部批次、过时代际、透明后恢复与资源生命周期。
