## Entry and source facts

负责人明确提前转向 Globe，G1 不再等待完整 M1；V3D、剩余 V4/V5C 与 V6 保留原状态。
当前 Globe 自身拥有默认 EllipsoidTerrainProvider 与 surface quadtree，Scene 已在 GLOBE 后
复制 depth，再执行 TERRAIN_CLASSIFICATION。现有地图前端只使用投影米制 XY，Globe 适配
无需修改 decoder 或接入 experimental MVT。现有平面凸体、Z=0 比例和 XY anchor 必须分离。

## Implementation

1. SceneGISVectorTileLayer 接受 live WGS84 Globe / SCENE3D，source 保持独立 EPSG:3857 单根矩阵。
   默认自动创建该 source scheme，可显式传入匹配的 scheme；不得把 Globe 地形 scheme 当成 MVT scheme。
2. 独立 Globe cover 采用地理包围体、三维距离 SSE 和 horizon culling，复用有界请求与 resident cover。
   Style 比例采用视轴椭球交点；越过地平线时采用前向最近点，保持地图可见部分的比例契约。
3. Worker 对过大的源三角形细分，在每三角形局部 ENU 建立保守球面覆盖体；近处使用 double origin
   和相对坐标保持精度。片元从实际地表 depth 反算 geodetic/Mercator 坐标，恢复已有 coverage/style/pick。
   Background 单独消费地表 depth；不合成地图颜色 RTT，不删除或改造 Globe。
4. 圆点/文字映射为 ECEF。地形 mesh 的空间查询索引由现有 vector Worker 异步构建，主线程只查询
   索引与提交 anchor；不逐标注扫描整块地形。保持 atlas、placement 和 native derived pick。
5. 新增 Test/vector-tiles/globe-map.html，保留独立平面页；同源公开地图、默认椭球和真实地形开关，
   提供本地确定性页面/测试。先验证渲染、拾取、provider/LOD 与生命周期，再做实际交互测量。

## Validation and gate

与 anchors、隐藏/释放；完整 vector 回归防止平面退化。新增浏览器 E2E，build/types/release/package。

SCENE2D/morph 和大字形跨陡坡的连续贴合不据本阶段结果扩大资格。

## Current handoff

### Performance correction

负责人要求修复当前 Globe 倾斜视角性能，仍在 G1 内修正，不提前关闭阶段。
保留原相机、1432×1150 和数据覆盖；使用 WebGL disjoint timer 分离 GPU/CPU，
再按面线/标注/原生地表隔离。已复现 1812 commands：完整 GPU 34.2 ms，
仅原生 0.4 ms，保留标注/圆点 2.7 ms；主因在面线 ground 绘制。
已修复 indexed/shared VA、数值纹理合并、命令反复标脏、椭球地平线误留、fractional zoom
数值抖动。真实 terrain 使用固定三角形数据 flat varying variant；保守片元排除和受像素精度
约束的 Newton 收敛避免无效工作。Worker bbox 预计算、全模式大 varying 与透明默认值筛查
没有进入最终实现。详见 ADR-0070 与 G1 review 的性能回归记录。

实现与技术自审已完成，负责人于 2026-09-14 确认性能修正可接受，视觉与交互 gate 关闭，见 [G1 review](../reviews/2026-09-14-g1-globe-review.md)。
