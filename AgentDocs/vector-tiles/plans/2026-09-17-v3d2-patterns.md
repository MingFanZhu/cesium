## 源码事实

Style 使用 paint allowlist，四类 pattern 尚被拒绝。SymbolAssets 已拥有单个 sprite 请求、元数据和 GPU texture；
Symbols 仅在存在 symbol layer 时构造。Worker 将 fill/line 几何打包为普通 attributes 或 ground 数值表，
Globe 使用相同数值表并细分三角形。Extrusion 使用独立实体网格，Globe background 使用 surface-depth quad。
资源、构建、测试入口沿用 ADR-0030/0067；不添加 Worker entry 或改生成器。

## 实施方案

1. 扩展四类 paint pattern，支持字符串及返回名称的既有表达式；纹理颜色替代对应 color，opacity 继续乘材质 alpha。
   `image`/图像可用性 coalesce 需连同动态图片注册协议另行设计，不在本轮接入。
2. 共享既有 sprite loader/texture，在有 pattern 无 symbol 的 Layer 中也提供显式 ownership。
   元数据用于 Worker 准备各 feature 的 UV 矩形/尺寸；不按图案拆为逐 feature DrawCommand。
3. 面与背景使用源 matrix 的连续坐标；线使用已有沿线距离；建筑保留屋顶 XY 与墙面距离/高度坐标。
   保持 tile 精度和 atlas 边界采样；不承诺跨瓦片道路全局里程或 pattern crossfade。
4. 扩展 flat、ground 数值表、Globe 和 extrusion shader；保留原无 pattern 快速路径、光照、alpha 与 native pick。
5. 重新审计 Liberty 的两层 pattern profile；道路图案接入，湿地因额外 translate-anchor 继续排除。
   增加双世界本地功能验收入口，不使公网成为自动化前提。

## 验证与退出条件

Style/CPU/Worker Specs 验证表达式、米/像素、atlas 元数据与协议；真实 WebGL 检查重复纹理、透明空洞拾取、
邻接区域连续性、孔洞与地形、楼栋、资源共享和释放。有关页面 E2E 与固定代表视图检查画面及 warm/mutation 开销。
运行必要 build/types/release/三种实际交付入口。技术自审与 checkpoint 后进入 V3D3，最终人工视觉 gate 随四项汇总。
