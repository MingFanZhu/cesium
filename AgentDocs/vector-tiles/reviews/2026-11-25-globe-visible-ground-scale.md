## 同视角证据

在负责人打开的公开矢量地图标签页重新加载构建并恢复原 ECEF 位置、方向、俯仰 +1.64°、
高度 5.40 m 和 HDR/PBR Neutral 曝光 1.2。仅使用页面已有 Viewer 移动相机，示例源码保持原版。

| 项目         |     旧版 |     新版 |
| ------------ | -------: | -------: |
| 参考眼深度   |   5.40 m |  34.03 m |
| Style zoom   | 23.39707 | 20.74115 |
| 标注距离     |  21.60 m | 136.11 m |
| 当前可见瓦片 |       19 |       19 |
| 布局标注     |        0 |       64 |

以原相机高度每 0.01° 采样跨越地平线，最大单步 zoom 差约 0.00061。固定绕靶的旧 zoom
完全一致。Node 对同一视角的旧、新函数交替暖测，单次中位数约 0.36 → 2.63 μs；
普通 45° 俯视 0.34 → 0.43 μs。该测量针对尺度计算，未推断 GPU 帧时。
采样格未命中时沿用原回退，极薄边缘、其他视锥与相机姿态不共享本街景的视觉证据。
