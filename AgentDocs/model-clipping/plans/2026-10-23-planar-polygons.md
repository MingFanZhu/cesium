## Source facts

Model and Cesium3DTileset update their owned ClippingPolygonCollection; tile content borrows it.
Native collection update and tile intersection use spherical extents; native model vertex stage derives spherical coordinates.
Planar terrain already uses `_SceneGISPlanarClipping` and `SceneGISPlanarClippingFS` with rebased XY edges.
Model clipping runs after final geometry transformation and survives native pick/depth/shadow derivation.
GLSL is generated by `scripts/build.js`; Specs use the existing gulp test / Karma entry.

## Implementation

1. Add a real planar Model regression with two disjoint polygons and inverse mode.
2. Route native collection update/state/intersection/destruction to a collection-owned planar runtime.
3. Route model polygon pipeline to an owned shader adapter; reuse terrain edge parser and fragment logic.
4. Preserve actual world coordinates with CPU-rebased inverse-view transform, including node/instance/model transforms.
5. Validate Model and tileset render/pick/depth, dynamic edits, default Globe path and destruction.
6. Add a local example, document the contract and record review evidence.

## Validation and exit

- Focused real WebGL Specs reproduce failure then pass, including large offsets and inverse mode.
- Terrain and native clipping regressions, stable texture/program identity and no stable-frame uploads.
- Build/release/types, scoped lint/format, upstream patch audit.
- Browser visual check; remaining visual acceptance and large-scene performance limitations stated explicitly.

No phase split or automatic commit is required for this bounded integration.

## Implementation outcome

All six steps completed. The collection owns a lazy planar runtime; tile models borrow it, and the
model stage reuses the existing terrain fragment evaluator without extra passes or Workers.
Two integration details were confirmed during real tileset validation: publication must occur in
queueCommands after render flags are initialized, and collection removal must clear the tile model
reference. The latter adds Model3DTileContent to the original two-file upstream integration scope.

Seven new model/tileset Specs pass. Native polygon regression selections pass (54 and 9 tests,
with overlapping selection); terrain has 12 passing cases and one identical pre-change failure.
The review records the exact baseline exception, resource stability evidence and follow-up boundary.
`npm run build`, `npm run build-release`, `npm run build-ts` and `npm run tsc` passed.
Browser visual check passed for normal and inverse multi-region clipping. The project owner subsequently
requested a local commit on `scenegis/develop`. No SDK modification was performed.
