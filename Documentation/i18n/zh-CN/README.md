# 引擎 API 中文文档

本页与英文文档均从当前发行版本的引擎和 Widgets 源码生成，包含原生 API 和扩展 API。
使用右侧搜索框查找符号名称或中文说明，使用页面顶部的 English 切换到同一符号的英文页面。

中文翻译逐步完善。未翻译或原文已发生变化、等待复核的字段保留英文，
请查阅[翻译覆盖报告](translation-report.json)。API 名称、参数名、类型、默认值、
链接目标和示例代码保持原样；术语表统一坐标、渲染和资源所有权的表述。

SDK 网站可直接读取本目录的 [api-doclets.json](api-doclets.json) 和
[api-index.json](api-index.json)。符号 ID 与英文版本一致，locale 为 zh-CN；
每个文档条目的 i18n 字段列出已翻译和保留原文的字段。

类名带有 SceneGIS 前缀的独立扩展仍沿用实际公开名称。
发行入口、资源基址及最小调用示例见发行包根目录的 README.md。
