## 决策

2026-10-20 负责人确认高空是 GIS 的常见使用场景。局部球壳虽然改善近地天空，
但与无限延展的平面地表不一致，不能作为本项目保留的可选模式。
因此撤销下述试验实现，移除公共选项、模式分支、专用 helper 和示例切换。
保留本 ADR 及实施评审作为决策历史；以下描述不再代表现行 API 或运行时。

`SceneGISEnvironmentEffects.planarAtmosphereModel` 为可写属性和构造选项，值为
`flat`（默认）或 `local-planet`；Globe 不接受 `local-planet`。不改变其他默认值。
模式切换异步获取一套固定资产，完成 GPU 创建后与模式标识一起发布；旧代请求
不可覆盖新代。原有完整资源在加载期间继续显示，失败沿用既有 errorEvent/fail-closed 契约。

局部行星使用 BrunetonEarth 固定半径 6360/6420 km、密度、光谱和方向照度 atlas。
光学球心固定在当前相机水平投影下方 6360 km。平面世界坐标先在 CPU/eye-relative
坐标中消去大 XY，再以 `(relativeX, relativeY, absoluteZ + R)` 求光学位置。
所有方向仍为平面 ENU，法线不弯曲；天空与有限段空气透视使用相同直线及球壳边界，
地表/模型/矢量按同一光学位置采样直接和方向性间接照度。接收点仍来自真实平面深度。
天空反射、星光消光、云/高度雾的入射光也须消费所选模型，不能误读另一格式 LUT。
云层及额外高度雾本身仍为平面几何，模型切换不修改它们的参数。

不增加光线行进循环或逐帧 LUT 构建，不改变平面曲面、投影、拾取、太阳天文参考点、
SSE 或瓦片调度。材质使用共享 Shader 库和 uniform 分支；环境程序按模式编译，完整资源最多一套；
切换时允许一套候选资源的短暂峰值。新模式照度 atlas 与 Globe 同预算，strict flat
仍为原三纹理布局。资产与生成器不新增，不修改上游文件或构建器。

## 适用边界

该模式是局部天空近似，不是全球球面地理模型。平移时光学球心水平跟随相机，
相同局部场景具有平移不变性；固定远处地物的光学高度随相机移动连续变化。
高空保留完整球壳光程，真空不产生散射；平面地图依旧无限延展，不能呈现球面地平线
下的地物遮挡。远处地表可能位于虚拟大气之上，这是选用平面几何的明确代价。
使用范围由实景对照和负责人视觉判断决定，不通过调色、俯角阈值或额外雾遮盖。
